Traffic must pass through the Istio ingress gateway for weighted routing and
the X-Rollout-Track response header to be applied.

1. Get the ingress address (adjust the namespace or Service name if needed):

  export INGRESS_HOST=$(kubectl -n istio-system get service istio-ingressgateway \
    -o jsonpath='{.status.loadBalancer.ingress[0].ip}')

2. Send a request using the VirtualService host:

  curl -sSI -H 'Host: {{ .Values.istio.host }}' "http://${INGRESS_HOST}/"

3. Sample the distribution:

  for request in $(seq 1 100); do
    curl -sSI -H 'Host: {{ .Values.istio.host }}' "http://${INGRESS_HOST}/" \
      | awk -F ': ' 'tolower($1) == "x-rollout-track" {print tolower($2)}' \
      | tr -d '\r'
  done | sort | uniq -c

Do not port-forward directly to an application Pod or Service for this test;
that bypasses the VirtualService route which adds the marker header.
